# Low_level_programming
# Лабораторные работы по ассемблеру (4 курс семестр 1)

Учебные программы на языке ассемблера для Linux x86 (32-bit), использующие NASM и системные вызовы через `int 0x80`.

## Сборка и запуск

Для файлов с расширением `.asm`:

```bash
nasm -f elf32 file.asm -o file.o
ld -m elf_i386 file.o -o file
./file
```

## Описание лабораторных

Lab1.asm — находит цифру разряда сотен у целого числа, большего 999. Ввод числа с клавиатуры, проверка корректности данных и вывод результата.

lab2.asm — среди четырёх целых чисел находит порядковый номер числа, которое отличается от трёх остальных равных между собой чисел. Реализованы ввод, проверка и вывод номера.

Lab3.asm — находит натуральное число от 1 до 10 000 с максимальной суммой делителей. Выводит найденное число и максимальную сумму делителей.

lab4.asm — проверяет, является ли введённое число n полным кубом. Выводит сообщение, является ли число кубом, либо сообщение об ошибке ввода.

lab5.asm — обрабатывает массив из 20 целых чисел и число A. Вычисляет произведение элементов массива, модуль которых больше A, и подсчитывает количество таких элементов. Предусмотрена обработка ошибок ввода и переполнения 32-битного произведения.
